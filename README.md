# ☕ Coffee Sales Analysis

## Project Overview
This project analyzes coffee sales data to understand revenue, orders, product performance and customer buying patterns.

## Tools Used
- Excel
- SQL
- Power BI
- Python Pandas

## Key Analysis
- Total Revenue Analysis
- Total Orders Analysis
- Average Sales Analysis
- Best Selling Products
- Category-wise Sales
- Monthly Sales Trends

## Business Insights
- Identified top-performing coffee products.
- Analyzed sales trends to understand customer demand.
- Created an interactive dashboard for easy business decision-making.
